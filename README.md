# MoodFlix

MoodFlix is a full-stack web project for movie and series recommendations.

The website allows users to browse recommendations, search by filters, add reviews, contact the project developer, register, log in, and manage a personal watchlist.

## Technologies

- HTML
- CSS
- JavaScript
- PHP
- MySQL

## Main Features

- Responsive navigation menu
- Movie and series recommendations
- Search and filter system
- Review and rating system
- Contact form
- User registration and login
- Personal watchlist saved with MySQL
- Profile image upload
- PHP mood quiz without database
- Video integration

## Project Pages

- Home
- Recommendations
- Search
- Watchlist
- Reviews
- Contact
- Team
- Personal Info
